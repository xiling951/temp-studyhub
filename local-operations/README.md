# Archived local StudyHub operations

Archived on 2026-10-13 before removing local code and uninstalling the Desktop StudyHub plugins. The current application source lives at the repository root. This folder retains historical deployment, extraction, and verification scripts from the local workspace; machine paths and old versions in these scripts reflect their original context.

Textbooks, learning libraries, session data, credentials, raw model responses, and private screenshots are excluded. MANIFEST.json records the original relative paths and SHA-256 checksums.
