# 扫描教材图文：定制版使用说明

本功能基于 StudyHub v3.3.0，定制版本为 `3.3.0-scanned.22`。沿用 DSH 的附件、模型、权限和任务服务；旧资料和题目继续使用原来的文字引用和复习调度。云解析通过已配置视觉模型逐页转写、独立原图核验和有界修复，不要求 GPT 逐份复核。自动检查不能保证绝无转写错误；仍不确定的内容明确保留疑点及原页。

## 导入与阅读

1. 在「资料 → 添加资料」中开启扫描教材图文功能，选择 PDF 并选择「保留图文」。默认开关关闭。
2. 在「图文解析方式」选择「云端视觉模型」，再选择 Qwen `qwen3.8-flash` 或其他已配置且支持图片的模型。Flash 已真实接收原页和题图。首次使用可先导入 3–5 页；模型能力声明不代表 API Key 一定允许该型号。
3. 点击「保留图文并导入」，在「任务」页查看转写、独立原页核验、必要修复和裁图进度。每页明确差异最多重转写一次，再独立复审；格式或输出长度问题最多自动重试一次，仍失败可恢复。成功的逐阶段检查点和已完成页不会重复调用。旧已完成云缓存不会因升级重付，但也不会伪造新核验记录。模型路由在当前解析版本内固定。
4. 从资料列表点击「阅读」，查看图文、公式、章节和有明确原页锚点的跨页段落/续表；切换「原始 PDF」或「原页对照」定位。自动核验通过的页与仍不确定的页分别显示状态，不确定处始终保留原件。自动核验记录与人工验收身份分开。
5. 点击「导出图文教材」，ZIP 包含离线分章 HTML、MD 正文、结构 JSON、图片、原页映射和原 PDF。解压后打开 `index.html` 并进入章节阅读。全库附件备份与单教材导出是不同操作。

本地 MinerU 图文解析需要本机已验证的 MinerU 4.0.11 服务及 Python/PyMuPDF，适配器使用 `http://127.0.0.1:16580/v1`。云解析不依赖 MinerU 服务，但仍使用本地 Python/PyMuPDF 渲染页面及裁图。Python 可通过启动环境变量 `STUDYHUB_PDF_PYTHON` 指定。单原件上限 800 MiB、单图片 8 MiB；本地解析每组最多 10 页，云解析逐页进行。

## 图解与带图题

在「图解与核对」选择图片或页范围并提交解释。DSH 模型必须实际支持图像；本机验证使用 `deepseek-official/deepseek-flash`。没有视觉模型时仍可保存、阅读和导出图文，解释操作会明确提示不可用。

自动图解与 OCR 分开保存，默认待核对。修订或拒绝解释会保留历史；只有明确核对并选择索引的版本才进入检索。实施代理对原图的核对不等于用户本人批准。

在「设置 → 学习库与模型」选择 Qwen 作为生成模型；在「创建题组」选择资料页、填写主题，并在「选择图片证据」选取 1–4 张相关电路图、曲线或表格。普通生成、补题和修题的规划、答案准备、编题及独立审阅均读取真实图片。分步生成只继承该步骤对应页的图片。

独立审阅检查图像支持、答案、模型适用条件、引用、题干自足性、提示泄漏和其他题目的目标。图卡被拒绝后系统自动修订并重新看图，最多两轮，每题立即保存；原样失败不能通过再次恢复重置预算。正确的实际收据只有题文、原图、版本及模型路线都一致时才复用。仍不通过的题留在草稿并阻止发布，证据不足时如实保留缺额，不凑题。需要发布时使用草稿页的正常保存入口，无需 GPT 人工代改或批准。

题目在练习、考试、口试和错题详情中显示原图，并可定位原页。作答前不显示答案或辅助图解。题组 JSON 保存图像引用，但不包含教材附件；导入到缺失原教材版本的库不能发布，且导入的“已核对”标记不能替代新审阅。

## 检索和备份

指定主题进行全文覆盖出题时，系统先通过原生规划模型筛选相关页面，再安排题量；主题筛选失败会报错，不会退回按全书页面长度分配。每题审阅必须明确通过主题相关性和证据支持检查；缺失检查项会进行有限重试，证据不足的题不进入合格草稿。编辑草稿后重新审阅仍执行这些检查。旧题不会被自动改写。

按主题出题时选择相关图片证据，系统根据每题是否需要图片安排图文引用；无需图片的题使用正文证据。阅读器、创建题组及分步生成共用选图和独立审核流程，单批最多 30 题。中断后从任务或草稿继续：即使候选数量已满，也会只完成未决审核及剩余有界修订，不重新编题；已通过的相同题文、图片、版本及路线复用实际收据。自动审核先只观察原图，再结合观察结果独立审题，减少题干误述对看图的影响；完成的观察和审核按图片、资料版本及实际模型复用。仍不确定或未通过的题保留在草稿并阻止发布。旧审核标准不能直接批准新发布，已出版旧题继续可读。

检索扩展为可选组件。建索引时正文、适用图注和明确选中的已核对图解一并计算内容哈希；只修改图解也会重新索引对应页。检索命中图片在 StudyHub 内从当前教材清单恢复关联。历史版本默认不进入新题选材，已发布旧题仍可读到历史图像。

首次检索需要下载约 90 MB 的嵌入模型。搜索子进程使用既有 HTTP/HTTPS 代理路由；不接收模型 API 密钥。无检索扩展时仍可按章节或图片选择出题。纯图片页不伪造 OCR 文字来源，使用带图出题入口。

含图文附件的全库备份应使用 ZIP 备份入口；旧 JSON 备份不能完整保存这些附件，系统会拒绝不完整的图文库 JSON 导出。恢复 ZIP 先核验路径、资源、哈希和元数据，成功后再替换库。备份大小上限 2 GiB、展开大小上限 4 GiB。

## 保留定制功能

保存本次定制 TGZ 和 SHA-256 校验文件。保持原插件名称，安装时替换同名包，不同时启用整包与六个独立组件。不要在插件市场或 StudyHub 的上游升级入口安装普通上游版本：它会替换定制代码。可关闭 StudyHub 自动检查更新；更新定制功能应使用本仓库经验证的新定制包。

插件回退与数据回退分别执行，详见交付目录的 `install-and-rollback.md`。旧版可继续读取真实 OCR 文字，但不会提供新增图文界面；不要用旧 JSON 导出覆盖完整附件备份。
