# 扫描教材图文使用说明

本机已安装 `3.3.0-scanned.4`。双击桌面 `DSH Desktop`，打开有效的「学习模式 · StudyHub」会话即可使用。当前学习库为「数字集成电路-图文」，旧库 `.dsh-study` 保持原数据，可在设置中切回。新版支持云端转写及连续电子文本阅读；跨页段落、续表和整书准确性尚未完成验收。

## 立即开始反相器题组

在StudyHub选择「数字集成电路」课程中的「第5章 CMOS反相器 · 器件作用与去除」，或点击「回到题目 1/4」。四题均显示教材图5.1，可点击图片放大，点击「定位题图原页」查看PDF149页（印刷131页）。题目涉及器件去除、输入输出与电容负载；先自行判断，再翻面查看答案与评分要点。

题组已经实施代理对照原图修订，并通过真实独立图片审阅；尚未经过你本人逐题核对。需要修改题组时，先结束正在进行的练习；编辑带图内容会使旧审核失效，重新审阅后发布。

## 导入与阅读

1. 打开「资料 → 添加资料 → 扫描教材：保留图文」，开启「扫描教材图文」。选择「云端视觉模型」和 `qwen3.8-flash`，先导入 3–5 页扫描 PDF；暂不勾选「同时解释关键图」。点击「保留图文并导入」。
2. 在「任务」查看逐页识别、裁图及保存。云解析支持暂停、继续和重启后恢复。默认的本地 MinerU 仍需本机服务运行，旧本地任务的暂停/重启恢复不支持；572页约38分50秒是历史本地解析结果，不是云解析速度。
3. 从资料列表点击「阅读」，选择「图文教材」查看连续电子文本，切换「原始 PDF」或「原页对照」。检查文字顺序、公式上下标、电路连线、图注与表格；待核对标记不代表准确。
4. 在阅读器点击「导出图文教材」，保存 ZIP 后解压打开 `index.html`。资源包包含 `textbook.md`、结构 JSON、图像与原 PDF；核对正文和图片是否齐全。已有纯文字材料继续按原流程使用，模型解释不写回原文。

## 解释图片及出题

在DSH界面新建或打开有效的「学习模式 · StudyHub」会话。模型设置需选择实际支持图片的模型；本机已通过DSH原生凭据配置DeepSeek-V41-Flash，请不要把密钥写入题目、插件patch或学习库。

阅读器选择电路图/表格/曲线，可生成独立图解。图解默认待核对，先与原图比较，再修正/批准；只有明确选入的已核对图解影响检索索引。没有模型时导入与阅读仍保留，解释和出题显示不可用。

选择图像证据后生成带图题，规划、答案、成题、独立图片审阅均由原生任务执行。失败或被拒的结果保留待修订草稿；修正后重新独立审阅，通过后发布。普通文字引用与图像证据分别校验，不能伪造OCR引用。每次模型图片上下文1–4张，单张最多8MiB，模型调用可能计费，具体用量查看DSH原生记录。

## 检索与备份

检索扩展已安装；对所选资料建立索引后，命中可查看原图/原页并带图出题。未安装扩展也可导入、阅读、图解及生成题组。

在「设置 → 导入、计划与备份 → 含附件整库备份」导出ZIP。当前整本教材与最终四题的本机备份为 `D:/studyhub/implementation/packages/数字集成电路-图文与反相器题组.zip`。恢复时先选择空的新库；验证恢复将替换所选库。此包包含两历史版本、OCR、原PDF、图像、预览、题组及审核记录。

`full-textbook.zip`为单教材离线阅读包，解压后打开index.html，可离开StudyHub阅读。题组JSON只包含题目及引用，不携带教材图，不能替代含附件ZIP；跨库导入需要重新核验与独立审阅。含图文库不使用旧纯文字JSON作完整备份。

保留本地定制TGZ，避免市场/上游更新覆盖功能。安装、插件回退和旧库恢复见 `install-and-rollback.md`；实际验证及限制见 `测试报告.md`。
