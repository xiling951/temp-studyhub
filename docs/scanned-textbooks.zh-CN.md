# 扫描教材图文：定制版使用说明

本功能基于 StudyHub v3.3.0，定制版本为 `3.3.0-scanned.1`。沿用 DSH 的附件、模型、权限和任务服务；旧资料和题目继续使用原来的文字引用和复习调度。

## 导入与阅读

1. 在「资料 → 添加资料」中开启扫描教材图文功能，选择 PDF 并选择「保留图文」。默认开关关闭。
2. 首先使用「仅保存图文」。任务逐组解析，进度在「任务」页显示。可取消或重试；当前不支持暂停和进程重启后恢复任务，但重试会校验并复用已完成的解析窗口。
3. 打开资料，选择「图文教材」。页码栏表示导入 PDF 的页码，页面同时显示原书 PDF 页码及识别到的印刷页码。点击「原页对照」核对完整页面；图像可放大。
4. 保存原 PDF 使用分块下载，图文教材导出为 ZIP，内含离线 HTML、图像、公式样式和原 PDF。全库附件备份与单教材导出是不同操作。

图文解析需要本机已验证的 MinerU 4.0.11 公共服务及 Python/PyMuPDF。当前适配器使用 `http://127.0.0.1:16580/v1`；Python 可通过启动环境变量 `STUDYHUB_PDF_PYTHON` 指定。单原件上限 800 MiB、单图片 8 MiB，解析每组最多 10 页。

## 图解与带图题

在「图解与核对」选择图片或页范围并提交解释。DSH 模型必须实际支持图像；本机验证使用 `deepseek-official/deepseek-flash`。没有视觉模型时仍可保存、阅读和导出图文，解释操作会明确提示不可用。

自动图解与 OCR 分开保存，默认待核对。修订或拒绝解释会保留历史；只有明确核对并选择索引的版本才进入检索。实施代理对原图的核对不等于用户本人批准。

在阅读器选择 1–4 张相关图，填写想练习的问题并生成题组。规划、答案准备、生成及独立审阅都读取实际图片。未通过审阅的题留在草稿；编辑后需重新独立审阅，旧审核记录不能沿用。审核通过仍建议核对电路连接、条件和答案：真实验收曾发现模型把器件尺寸关系读反，系统拒绝了该草稿。

题目在练习、考试、口试和错题详情中显示原图，并可定位原页。作答前不显示答案或辅助图解。题组 JSON 保存图像引用，但不包含教材附件；导入到缺失原教材版本的库不能发布，且导入的“已核对”标记不能替代新审阅。

## 检索和备份

检索扩展为可选组件。建索引时正文、适用图注和明确选中的已核对图解一并计算内容哈希；只修改图解也会重新索引对应页。检索命中图片在 StudyHub 内从当前教材清单恢复关联。历史版本默认不进入新题选材，已发布旧题仍可读到历史图像。

首次检索需要下载约 90 MB 的嵌入模型。搜索子进程使用既有 HTTP/HTTPS 代理路由；不接收模型 API 密钥。无检索扩展时仍可按章节或图片选择出题。纯图片页不伪造 OCR 文字来源，使用带图出题入口。

含图文附件的全库备份应使用 ZIP 备份入口；旧 JSON 备份不能完整保存这些附件，系统会拒绝不完整的图文库 JSON 导出。恢复 ZIP 先核验路径、资源、哈希和元数据，成功后再替换库。备份大小上限 2 GiB、展开大小上限 4 GiB。

## 保留定制功能

保存本次定制 TGZ 和 SHA-256 校验文件。保持原插件名称，安装时替换同名包，不同时启用整包与六个独立组件。不要在插件市场或 StudyHub 的上游升级入口安装普通上游版本：它会替换定制代码。可关闭 StudyHub 自动检查更新；更新定制功能应使用本仓库经验证的新定制包。

插件回退与数据回退分别执行，详见交付目录的 `install-and-rollback.md`。旧版可继续读取真实 OCR 文字，但不会提供新增图文界面；不要用旧 JSON 导出覆盖完整附件备份。
