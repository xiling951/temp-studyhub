# StudyHub 扫描教材图文功能：具体实施计划

日期：2026-10-09。状态：计划已生成，项目代码尚未修改。

## 1. 实施目标与完成标准

以本机 StudyHub 3.3.0 和 DSH Desktop 0.11.1 为基线，实现扫描教材图文导入、原页对照、关键图解释、带图检索与出题。用户重新导入教材后，应得到一本有真实图片、正文、公式和表格的图文资料，所有内容能回到原 PDF 的页码与位置；图像解释与教材原文分开，并明确显示待核对状态。

完整范围必须走到本文 T12，不应在裁图脚本、一个独立展示页或仅文字导入完成后宣称整个项目完成。T01–T07 完成后可以交付“图文保存和阅读”，T08–T09 完成后再交付“模型解释图片”，T10–T12 完成后才能交付“StudyHub 根据图像出题并可日常使用”。

本轮只制定计划。新会话接到实施指令后，可在独立源码、隔离运行环境和测试库中执行开发、测试、打包；正式安装和正式库操作依据该会话的实际授权范围执行。每阶段验证通过后自主继续，无需逐项询问常规开发选择。

## 5. 数据与接口的固定边界

T03 决定最终字段名之前，使用以下“新增、可选、独立版本”的设计原则：

- 新图文文档的 identity 可依据原 PDF hash；旧 documentId/sourceId/revision 不重命名，原文件 hash 作为额外关联。
- `documents.versions` 保持既有 sourceIds；新增可选图文描述符（暂名 `visual`），引用不可变的文档清单、原文件资源、解析指纹和完成状态。
- 清单包含全部原页记录；页记录含物理页号、可选印刷页号、内容块、真实文字 sourceId 或 null、资源引用和质量状态。不要给无文字页伪造正文。
- 内容块保留类型、阅读顺序、坐标系、bbox、图注/图号和父子关系；文字定位与原文字符偏移分离。
- 资源记录包含不透明 assetId、类型、哈希、字节数、MIME、尺寸和所属页/块。路径仅由材料资源服务生成，不能由模型或前端提供任意本地路径。
- 图解为独立版本化记录，记录资产 hash、上下文版本、模型路由、结果、核对状态与失败原因；不插入旧 source.text。
- 新的 visualCitations 不替换普通 citations；普通原文引用校验继续严格执行。
- 默认保持全库 store.version=4，不提高全库版本。若实现证明无法用可选扩展达到目标，先记录具体原因和迁移/回退设计，再处理；不能静默引入旧程序无法读取的升级。
- 新模块仍归 materials 等现有 Context 的端口管理；新集合和操作必须在 schemas、fields/collections/defaults、读写及 grants 中注册。
- 功能总开关默认关闭，用户按文档选择图文导入。开启后也不切换旧资料的普通导入路径。

所有临时接口名须在 `decisions.md` 标为“建议名称”或“已实现”，不能让实施代理把建议当作现有 API。

## 6. 顺序执行的任务

### T01 / M0：取得源码并建立基线

依赖：无。

工作：取得 StudyHub `v3.3.0` 完整源码，读取其项目规则，记录完整提交号和锁文件；对照本地包的重要后端文件和 package exports。安装开发依赖，记录 Node、DSH、MinerU 和运行配置的非敏感部分。准备隔离 harness/library，并在原版源码上运行 lint、test、build、release:check 与适用的 DSH smoke。

不要全盘复制 harness 的凭据、会话和缓存作为测试环境。需要模型时优先使用 DSH 公开配置/既有授权方式，密钥不得打印、提交或硬编码。

交付：`evidence/environment.md`、`baseline-results.md`、源码 commit、隔离启动记录。

通过条件：能解释测试环境与正式环境的区别；已安装包与源码的差异有记录；能够在隔离库启动原版插件；已有失败单独归档，不被记成新功能通过。

### T02 / M0：验证两条外部接口

依赖：T01。

解析接口：用 7 页样例验证 MinerU 4.0.11 的公开结构化结果和资源导出。确认真正的内容协议、图片资源是否存在、bbox 单位/旋转、分页基数和多子图。不能把 `mineru parse --json` 命令状态响应误当作结构化教材；不能把当前 main 的命令选项套给本机版本。

宿主接口：验证 DSH 的实际附件服务、模型目录 inputModalities、原生图像块，以及认证消息桥的请求限制。检查图文文件读取是否可以扩展为认证资源服务；若不能，则选消息桥分块读取。图像真实调用留到 T08，避免在所有接口未厘清前重复付费调用。

交付：`evidence/mineru-contract.md`、`dsh-capabilities.md`、小样例原始结果和坐标对照。

通过条件：可以从公开解析结果取得图像或可定位的裁图区域；若本机 CLI 没有公开结构化输出，明确记录可用的同版本公共 SDK/API 适配路径和依赖。不要将内部缓存目录作为最终路径。确认宿主支持哪些操作，不把声明类型当成已成功调用。

### T03 / M0：确定契约、功能开关和资源规则

依赖：T02。

工作：落实第 5 节的 schema；设计 materials 图文提交、页面查询、资产元数据、分块读取、教材导出和图解操作。操作参数以 documentId/revision/assetId 为范围，不透传任意磁盘路径。注册契约、集合、跨 Context grants 和 requiresModel；明确只启用 materials、没有 audio/generation/retrieval 时的行为。

新大文件通道与旧 `document.bytes`/base64 附件接口分开。初始沿用 800 MiB 上传允许值，但将存储、解析内存、预览分辨率、单次模型图像预算分别配置。

交付：`decisions.md` 中的契约和依赖关系，功能开关实现，相关契约/权限测试。

通过条件：关掉功能后原版路径不变；没有模型仍可以保存/浏览图文；越权或跨库资源访问被拒绝；同库历史版本仍可读取。

### T04 / M1：原 PDF 与资源存储

依赖：T03。

工作：新增流式原文件复制与哈希校验、不可变资源落盘、暂存区和清单引用。区分解析上传的临时文件与永久文件；复用上传注册表和现有文件准入，不自行猜测临时目录。图片按 hash 去重，资源归属与版本引用不能因去重丢失。

沿用 Store 事务：文件先完成和校验，再把资源清单提交到文档版本。事务失败保留旧文档可读，仅留下可回收的无引用文件。先实现保守回收策略；归档/切换版本/取消任务都不能删除仍被旧题或旧版本引用的图片。

交付：存储模块、取消/事务失败/资源校验测试，原件与复制件哈希证据。

通过条件：188.9 MiB 原书复制成功且 hash 相同；没有整本 base64 返回；中断写入不会发布半成品；原始教材不被修改。

### T05 / M1：图文解析与分段合并

依赖：T04。

工作：为 MinerU 引入结构化适配器，保存正文、公式与编号、表格结构、图注、图片、页码与阅读顺序。图片资源缺失时按经验证的 bbox 从保留 PDF 裁图；无有效 bbox 时保留原页回退，不猜测区域。提取分辨率可配置，导出的清晰度不超过原扫描本身的细节。

复用现有分页、失败拆段、取消与重试。缓存 fingerprint 覆盖原文件、解析器版本、模式、页范围和适配器/资源格式版本；旧文字缓存仅供文字复用，图文齐全另行校验。不能因已有文字缓存跳过图片补全。

按段落盘和验证，再合并全书。图片页与空白页保留页记录，状态分别标注；只把真实 OCR 正文投影为旧式 source.text。记录来源是 OCR、原 PDF 文字层或模型解释，不混淆。

交付：样例图文清单、图片资源、分页映射、质量报告和合并/重复导入/缺失资源测试。

通过条件：7 页样例的第 1 页可对照原 PDF 第 200 页，包含图 6.14、6.15 的子图与图 6.16；坐标、图注和子图关联经视觉检查。不存在资源但有文件名时不得标为成功。原书导入时页号使用原 PDF 页号，不误用样例的局部编号。

### T06 / M2：图文阅读器与认证资源传输

依赖：T05。

工作：在 ui 源码加入扫描教材导入选项、分阶段状态、图文正文、原页对照、图片放大、公式/表格渲染。页记录懒加载，图片按可见区域加载，原页按需生成；不要一次将 572 页和全部图片加载到浏览器。

先实现现有认证桥上的有界读取；宿主公共路由能力已在 T02 验证时才使用 HTTP Range。不能给浏览器发裸磁盘路径当作资源，也不能新增未鉴权文件服务。添加原文件下载和页面/资产定位；公式或图无法解析时给原区域入口。

交付：浏览器/桌面截图，阅读性能记录，认证/分块读取和主要交互验证。

通过条件：7 页样例真实可读；没有模型仍可浏览；点击图片能找到原页；切换章节不会加载全书；旧 PDF/Word/PPT/Markdown 阅读与文字选择、翻译、批注保持可用。

### T07 / M2：教材导出与整库备份恢复

依赖：T06。

工作：新增两类明确操作：单本教材图文导出、含新附件的完整学习库备份。前者包含原 PDF、可阅读 HTML、Markdown、figures、JSON 清单及质量报告；后者保留课程、题组、复习状态、旧附件和历史图文资源。图解存在时另带其版本记录。

使用流式压缩/分块下载和有界恢复，不突破旧 restore 请求限制。旧 JSON 备份仍能恢复，小文件旧导出语义保留；旧格式无法携带新资源时明确提示，不能成功返回一个缺图的“完整备份”。清单和 hash 全部验证后才提交恢复；压缩包路径和展开量受限。

交付：一次导出→新测试库恢复→逐资源校验的记录，以及可离开 StudyHub 阅读的图文包。

通过条件：恢复后旧题和图像引用可读、SM-2 状态一致；坏包/缺图/错误哈希不会覆盖现有库；新大文件不通过旧整包 JSON 通道。

里程碑 A：完成图文教材保存、阅读和备份。此时继续 T08，不把图文保存说成图片已被理解。

### T08 / M3：DSH 原生带图调用

依赖：T07。

工作：新增显式结构化模型入口，使用 DSH 附件服务取得有效 ImageAttachmentRef，并输入用户 image 块。保持旧 complete(system,prompt) 行为；同时接通 direct/subagent 路径、取消、超时、错误转换、用量统计和模型能力检查。不能只在文本中保留 data URI，也不能关闭通用图片清理器。

优先从实际目录选 DeepSeek V4.1 Flash 对应路由，官方 API 名是 deepseek-flash，但 provider/model 以本机注册为准。处理能力未知、无视觉能力、图片超限和 offload；只传占位文字时不能声称看到了图。

初始每次选择 1–4 张相关局部图并附上下文，按宿主/provider 实际预算分批，不上传全书。未经必要授权，不上传整个教材到额外服务。

交付：包含实际图像附件的调用验证，成功/不可用/offload/取消路径证据和统计记录。

通过条件：真实 V4.1 Flash 能回答一张测试图中只有图像包含的信息；并用请求组装测试证明不是只送图注。旧纯文本调用正常，用量记账一次；实测需要 DSH 模型授权时只使用已有公开配置能力。

### T09 / M3：图解后台任务与核对

依赖：T08。

工作：在现有 Jobs/gateway 下注册图解任务，沿用宿主 executor；不得另建后台任务表。阶段可取消与重试，恢复/暂停只在实现后声明。保存独立解释版本、已选上下文版本、模型路由、结果和看不清的标注；默认待核对。

界面支持导入时“仅保存图文/同时解释关键图”，以及后来按章节补解。没有视觉模型、解释失败或取消，不影响已保存图文。提供人工核对/修正，保留历史解释，不能把自动解释改成教材原文。

交付：一小组电路/曲线/表格图的解释结果，进度/错误/重试/核对界面，任务生命周期与资源释放验证。

通过条件：图像解释状态与图文解析状态分别显示；重复执行复用匹配版本，模型/上下文变化产生新记录；取消后停止实际调用并保存已完成结果，不无限重试。

### T10 / M4：图像证据与带图题全链路

依赖：T09。

工作：新增 visualCitations 的 schema 和校验器，至少绑定文档版本、页码、assetId、图像 hash、区域及核对状态。普通 citations 继续原文检查，不能用 importedFromJson 或虚构文字绕过它。

规划、答案准备、生成和审阅均取得所引用的实际图片；各阶段模型无视觉能力时明确限制，不静默作出看图结论。区分原图证据和图解辅助；只含图像的题必须走独立图像验证链，不能仅凭文件存在就发布。

更新草稿、编辑、发布、publicCard 等返回投影、练习/测验/闪卡/考试/口试/错题显示、题组 JSON 导入/导出和历史引用。作答前只显示必要原图，不提前返回答案或图解。

交付：一组真实带图草稿与发布验证，证据校验测试，各主要练习界面验证和题组导出/导入记录。

通过条件：匹配版本图片可见，引用回到原页；跨文档/错版本/篡改图片/缺失证据不能发布；文字引用规则未放宽；旧题作答和 SM-2 调度一致。证据格式正确与答案正确分别检验。

### T11 / M4：图文检索与索引变更

依赖：T10。

工作：保持 mcp-local-rag 现有工具契约，先从 sourceId 在 StudyHub 侧解析文档版本与图像映射。不假定修改启动检索扩展即可获得新 metadata。

交付：正文不变、图解变化时重新索引的测试，检索命中图片定位证据，以及扩展缺失时降级验证。

通过条件：图片关联不会被 normalizeHits 丢失或可由权威源映射恢复；不会把旧版内容混入新题；缺检索扩展时章节选择和普通出题可用。

里程碑 B：完成图像解释、带图出题及图文检索。仍需 T12 形成正式交付证据。

### T12 / M5：全书、回归、打包与安装准备

依赖：T11。

工作：在隔离库导入 572 页原书并测量耗时、峰值内存、磁盘和失败重试。核验原件哈希、页码覆盖和所有资产引用；抽查图文混排、旋转页、纯图片页、复杂公式、表格、多个子图和书末页面。检测区域数量不是独立图号数量，不用历史统计当作固定验收数字。

真实桌面 profile 集成测试涉及用户当前环境时，先准备原包、配置和学习库备份，明确实际安装目标及回退；没有正式安装授权时先交付可安装包和隔离测试证据，不修改当前 profile。独立 harness 的通过不能代替桌面测试通过。

构建带可区分版本的定制 tgz，核对 package exports、插件名称、依赖范围和检索包版本。定义防止上游更新覆盖定制功能的部署方式，不能随意改变包名导致插件作用域重复。交付 SHA-256、安装/回退说明及实际测试范围；数据回退与插件回退分别记录。

交付：`packages/` 内可安装产物和校验值，`evidence/final-validation.md`、`install-and-rollback.md`、最终 `progress.md`。

通过条件：全书在实测机器上可完成并浏览；原图和全部引用资产可读取；关键旧功能无新增失败；新功能状态如实；在新环境可安装/恢复；有明确残余限制。

## 9. 最终日常使用验收

按实际界面完成一次：拖入扫描教材 → 选择“保留图文” → 解析并检查 → 打开第 200 页对照 → 解释一张电路图 → 按章节生成带图题 → 审阅/发布 → 做题并查看原页引用 → 进入复习 → 导出并恢复到新测试库。

默认学习模型可使用本机 DSH 中经过验证的 DeepSeek V4.1 Flash 路由；缺图、缺模型、未核对结果均显式显示。不得承诺 OCR 或电路解释百分之百正确。完成的标准是原始信息保留、证据关联有效、实际输入链路打通、旧功能经回归，以及未完成/不确定结果可见。
